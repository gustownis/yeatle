# Yeatle 1.12.0

This release adds accounts, leaderboards and a Daily streak badge.

## New

- **Leaderboards:** a 🏆 button in the header opens boards for Daily, Stems, Snippets and Karaoke. Daily ranks by current 🔥 streak, then wins. Stems and Snippets rank by songs solved in the current catalog. Karaoke ranks by the sum of each song's best score.
- **Accounts:** create an account with a username and password (no email). Passwords are stored as scrypt hashes on the shared website. Logging in on another device merges progress from both devices, and progress syncs in the background after each round.
- **Daily streak:** the 🔥 badge counts consecutive UTC days with a finished Daily. On the leaderboard, a Daily counts when it's played on its day.
- Prestige is respected across devices: a device still on an older prestige cannot restore songs that a newer prestige cleared.
- The desktop app and local servers use the accounts on the website set by `dailyAuthority`, the same as the shared Daily. If that website is unreachable, nothing is saved to a separate local account.

## Fixes

- The 🔥 badge on the header button now updates as soon as a finished Daily syncs, instead of keeping the old number until the leaderboard is reopened.

## Verification

Linux x64, Node.js 22: all 148 automated tests passed. A local server with `dailyAuthority` set to an empty string was checked with real requests for sign-up, duplicate names, ranking and the five-try login lockout. Headless Chromium checked the header button on Stems, Daily and Karaoke at desktop and phone widths, account creation from the popup, and the streak badge updating after a Daily finished.

Windows and macOS were not tested for this release, and desktop packages were not built.

## Updating

Choose **Help → Check for Updates**, or download the matching app from this release. Settings, songs and saved progress are preserved. Existing progress joins an account the first time you log in on that device.

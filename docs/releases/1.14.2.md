# Yeatle 1.14.2

This patch release adds the full 2093 pre-master recordings for **U Should Know** and **Team ceo**, improves playback and microphone reliability across Stems, Snippets, Daily, Karaoke and Wrapped, and streamlines desktop HQ stem downloads and updates.

## Catalog

- **Full 2093 audio for U Should Know and Team ceo.** Released rounds for **U Should Know** (`3:06`) and **Team ceo** (`3:17`) now play their full pre-master audio instead of 30-second previews.

## Fixes and improvements

- **Stems and Snippets playback.** Autoplay blocks on mobile and Safari now pause the player cleanly instead of skipping the active round, short tracks clamp snippet timers to the track duration, the "Only instrumental" reroll deals a new song in local rounds, and broken era covers hide cleanly without interrupting the Eras picker.
- **Wrapped and Daily.** Wrapped counts 1st-try and subsequent-try solves accurately from each round's solved level, retries song metadata if a first request fails, and fixes the January 1-7 year counter. Daily stays in sync across open tabs and after signing in or returning from the browser's back-forward cache.
- **Karaoke.** Microphone pitch detection scales its analysis window automatically on 96 kHz and 192 kHz audio interfaces, closing the calibration window stops scheduled tones immediately, pausing a song pauses the rendering loop to save CPU and battery, high microphone delay settings score the end of the final phrase before showing results, and LRC word tags preserve leading words and `<mm:ss:cc>` timestamps.
- **Desktop app and HQ stem downloads.** Clipboard copy, screen wake-lock, and native macOS Edit shortcuts (`Cmd+C`/`V`/`X`/`A`/`Z`) work in desktop windows, update downloads only rebuild the application menu when progress text changes, and HQ stem downloads keep inactivity and cancel timeouts active while streaming and wait for Windows file handles to close before moving completed files into place.
- **Server performance and reliability.** Audio streaming and static byte-range requests handle `HEAD` without downloading or streaming full files, expired upstream preview links refresh automatically, cover requests coalesce in flight, and stem hash caches prune removed folders automatically.

## Verification

Windows x64 (Node.js 24.15.0, Electron 44.7.0): the automated test suite passed (`npm test`), and the Electron desktop, Daily and HQ stem download smoke checks (`scripts/desktop-smoke.cjs`, `scripts/daily-smoke.cjs`, `scripts/desktop-stems-smoke.cjs`) passed against local servers. The GitHub Actions workflow runs the test suite across Windows, macOS and Linux before building each package.

## Updating

In the desktop app, choose **Help → Check for Updates**, or download the 1.14.2 installer for your computer from this release. Settings, songs and saved progress are preserved.

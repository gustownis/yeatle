# Yeatle 1.13.4

This patch restores microphone access in Karaoke on the desktop app.

## Fixes

- **Karaoke microphone access in the desktop app.** Fixed a desktop permission check where Karaoke's hidden `about:blank` audio frame was rejected before reaching your computer's microphone, and added a fallback to the main window's microphone API if an iframe request is blocked.

## Verification

Windows x64: the automated test suite passed 192 tests with one Windows symlink skip, and an Electron desktop smoke test verified that Karaoke opens the microphone and lists audio input devices without error.

## Updating

In the desktop app, choose **Help → Check for Updates**, or download the 1.13.4 installer for your computer from this release. Settings, songs and saved progress are preserved.

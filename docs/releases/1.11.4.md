# Yeatle 1.11.4

This patch makes HQ stem downloads easier and fixes song answers, recording
metadata and source selection.

## HQ stem downloads

- **Check all** selects available songs in the current search. Use
  **Download selected** to queue them together. Installed songs and conflicting
  folders are skipped; selecting songs alone starts no download.
- The download popup's menu bar stays hidden when the updater refreshes the
  application menu, including after a manual update check.

## Song and playback fixes

- A page load replaced by navigation no longer shows a false **Yeatle could
  not start / ERR_ABORTED (-3)** error. Genuine loading failures are still reported.
- Released, Unreleased and Stems only now use their own playable recording and
  metadata. Switching between sources cannot reuse another recording's audio
  preparation job. All songs keeps the existing source quality preference.
- **Cant See (LS V2)** and **Cant See (Alivë)** have distinct labels. The HQ pack
  is correctly attached to LS V2; Alivë keeps its own audio. Saved HQ rounds
  retain their attempts and clip start when the pack's metadata is corrected.
- **Addicited** displays as **Addicted**, and either spelling answers the
  verified recording. **Now LS** stays distinct from AftërLyfe's **Now**.
- Maintained Watchu/Whatchu spellings also work with the correct guest credit.
  Popout's open verse is labeled separately from the completed KillBunk feature.
- Producer-only tracks such as **AMG C63** are excluded from new rounds.
  Both **Fleek** entries and the original **Zaza** without Yeat are excluded.
  **YEET featuring Yeat** and **GOONIE's Zaza featuring Yeat and Kankan** remain.
- Existing song ids, completion, lyrics, best scores, downloaded files and
  pinned Daily challenges are preserved. Verified equivalent recordings share
  suggestions and completion without merging unrelated vocal performances.
- Daily and Karaoke use clean `/daily` and `/karaoke` links. Older links still
  work and redirect with their query strings and fragments intact.

## Verification

The Windows automated suite passed 134 tests with one symlink-permission skip.
Actual browser and Electron checks covered the HQ picker, menu refresh,
catalog answers, saved rounds, desktop navigation, Karaoke controls and
shared Daily playback. The website's deployed catalog was also verified,
including byte-identical Daily audio before and after the fixes. See the
[catalog follow-up report](../testing-windows-catalog-followup.md) and
[HQ picker and routes report](../testing-windows-post-1.11.3.md).

Release package checks are recorded in the [1.11.4 release verification](../testing-windows-1.11.4.md).
The packages are unsigned. Physical microphones, singing accuracy and native
macOS/Linux device behavior were not tested on this Windows PC.

## Updating

Choose **Help → Check for Updates**, or download the matching app from this
release. Windows installer and Linux AppImage users can choose **Install and
Restart**; other package types finish installation manually. Settings, songs
and saved progress are preserved.

`SHA256SUMS.txt` provides download checksums. The three `latest*.yml` files are
updater metadata.

# Yeatle 1.11.0

This release adds a shared Daily challenge and Base Snippets, with six clips from 0.1 to 15 seconds.

## New

- **Daily:** everyone gets the same song and explicit clip start from the public website. Each wrong guess or skip uses one of six tries and unlocks a longer clip: **0.1, 0.5, 1, 3, 7, 15 seconds**. The next song arrives at **midnight UTC**.
- Daily saves unfinished rounds and completed results in the current browser/profile. Share your date, score, six squares, and link without revealing the answer. Native sharing, clipboard copying, and selectable text are supported.
- **Base Snippets:** the first/default practice difficulty uses the same six lengths and separate practice statistics. Existing difficulty preferences are preserved. Daily never changes practice statistics.
- Desktop Daily uses the existing transitions to/from Stems, Snippets, and Karaoke. Browsers navigate immediately; reduced motion disables desktop animation.

## Fixes

- Retry failed Daily audio without spending a try or changing the challenge. Shared-host failures do not select a local substitute. Local libraries, filters, and client clocks cannot change the shared challenge.
- Restore playback after changing the practice song pool while retaining the same song. Empty saved song lists no longer hide valid local stem packs when the tracker is unavailable.
- Keep **No mic (just watch)** selectable before granting microphone permission in Karaoke, and use the singular wording for a Daily win on the 1-second clip.
- Keep Karaoke's countdown zoom inside the note lane, preventing flashing horizontal/vertical scrollbars during the count-in.
- Reject incomplete saved losses and featured-artist-only answers. Preserve valid title aliases.
- Install the current operating system's Electron executable explicitly during desktop dependency setup. Windows test tools keep their reports if a terminal output pipe closes.

Real local MP3 renderer/browser checks covered all Base lengths, Daily persistence and retries, sharing branches, independent authority clients, desktop transitions, and Karaoke controls.

## Updating

On desktop 1.9.1 or later, choose **Help → Check for Updates**. Windows installer and Linux AppImage users can download, then choose **Install and Restart**. Mac, portable Windows, and Linux DEB users download inside the app and finish installation manually.

- Windows: choose `Yeatle-Setup-1.11.0-windows-x64.exe` or `Yeatle-1.11.0-windows-x64-portable.exe`.
- Mac: choose the `mac-arm64` DMG/ZIP for Apple Silicon or `mac-x64` for Intel.
- Linux: choose the `linux-x64` or `linux-arm64` AppImage/DEB.
- Local browser version: [download the 1.11.0 ZIP](https://github.com/gustownis/yeatle/archive/refs/tags/v1.11.0.zip) and keep your settings and song folders when updating.

The `latest*.yml` files are updater metadata; `SHA256SUMS.txt` provides checksums. Players only need their app download. Game progress, settings, song files, and admin passwords are preserved.

Hosted operators must deploy the full project, preserve their existing config and `daily-challenges.json`, set `dailyAuthority` to an empty string and `dailyPublicUrl` to their public Daily URL, and restart the single authoritative server. Normal clients retain `https://playyeatle.duckdns.org` as their Daily authority. See the [host setup](../../test-1.11/README.md#shared-daily-host-setup-required-before-public-launch).

# Yeatle 1.13.8

This release unifies volume controls across game modes with consistent purple sliders, mute buttons, and live numerical volume percentage readouts across Stems, Snippets, Daily, and Karaoke.

## What's new

- **Live volume percentage readouts.** Volume sliders across Stems, Snippets, Daily, and Karaoke now display an exact percentage readout (`0%` to `100%`) beside the slider in tabular figures, immediately reflecting adjustments and showing `0%` when muted.
- **Uniform Daily volume controls.** Replaced the plain "Volume" text label and unstyled slider in Daily with the matching mute/unmute speaker icon button, purple accent slider, and live percentage readout used in Stems and Snippets, and synchronized volume level preferences across modes.
- **Karaoke stage volume bar styling.** Updated the in-song stage volume control in Karaoke to use the uniform SVG speaker icon, purple slider accent, and dedicated percentage readout.

## Verification

Windows x64: the automated test suite passed 196 tests with one Windows symlink skip, covering uniform volume bar styling and percentage displays across Stems, Snippets, Daily, and Karaoke.

## Updating

In the desktop app, choose **Help → Check for Updates**, or download the 1.13.8 installer for your computer from this release. Settings, songs and saved progress are preserved.

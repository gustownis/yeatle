# Yeatle 1.11.5

This patch removes the requested non-Yeat recordings from the game while keeping their versions with Yeat available.

- Excludes 60 specified tracker entries from new rounds, suggestions and HQ stem downloads, including early solo demos, reference tracks, producer-only tracks, the fuëgo instrumental and the Eaters release without Yeat.
- Same-title songs now choose an eligible recording when a removed demo was previously preferred. Birthday, Pull Up, Dope Sickk and Not Da Same keep their versions featuring Yeat; full recordings retain their preference over streaming previews.
- Exclusions also apply to older song caches and listed demos that gain playable links later. Unrelated versions and artist credits are preserved.
- Existing saved rounds, downloaded files, completion and pinned Daily challenges retain their original recordings and progress.

## Verification

The Windows automated suite passed 138 tests with one symlink-permission skip. A browser check covered the excluded suggestions, all four song pools, retained Yeat features and completion of an existing saved round. See the [catalog verification](../testing-windows-catalog-exclusions.md) and [1.11.5 release verification](../testing-windows-1.11.5.md) for the checks actually performed.

The packages are unsigned. Physical microphones, singing accuracy and native macOS/Linux device behavior were not tested on this Windows PC.

## Updating

Choose **Help → Check for Updates**, or download the matching app from this release. Windows installer and Linux AppImage users can choose **Install and Restart**; other package types finish installation manually. Settings, songs and saved progress are preserved.

`SHA256SUMS.txt` provides download checksums. The three `latest*.yml` files are updater metadata.

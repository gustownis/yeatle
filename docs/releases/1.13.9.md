# Yeatle 1.13.9

This release keeps the game responsive when many people play at once, fixes usernames being cut off in the leaderboard button, and makes the app lighter to download and open.

## What's new

- **Fixed username descender clipping in the leaderboard button.** Letters such as `g`, `y`, `p`, `q` and `j` now show their full lower loops in the header button and in leaderboard rows, at the same button height as before.
- **Faster song suggestions.** The guess box lists the 10 best matches, so typing stays smooth on phones.
- **Lighter page load.** The 21.7 MB AI splitter now loads only when a song actually needs it. Rounds with hand-made stems, Snippets, Daily and Karaoke no longer download it.
- **Smooth return from Daily and Karaoke.** Going back to Stems or Snippets shows the full game straight away again, instead of an empty list that fills in and grows after the page appears. Snippets keeps the round's space while the next round is dealt.
- **Optimized asset payload.** Unused images and duplicate media were removed from the app, and the explosion sound is now a short audio file instead of a video, making it about 3.3 MB smaller.
- **Updated desktop preview.** The README shows the current interface.

## For server hosts

- **Server state saves run asynchronously.** Account changes are written in the background at most about once a second and are saved before a normal shutdown, so saving no longer holds up gameplay and audio.
- **Cached daily round audio.** Daily and Snippets songs are kept in `.tmp/audio-cache/`, up to 512 MB, so replays and seeking don't return to the song host.
- **Faster leaderboards.** Rankings are shared between requests for up to 5 seconds and update immediately when a result, sign-up or rename changes them.
- **Lighter song list requests.** Browsers revalidate the song list and skip the download when it hasn't changed.
- **Song list refresh limit.** On hosted servers, anonymous `?refresh=1` requests can rebuild the catalog once every 15 minutes. Signed-in admins and the desktop app are not limited.
- **More capacity for sign-ins.** The server's worker pool is larger, so a burst of logins doesn't delay file access.

## Verification

Windows x64: the automated test suite passed 211 tests with two platform skips. Chrome checks on Windows covered the leaderboard button at desktop and phone widths and confirmed the AI splitter is not requested on load for rounds that don't use it.

Linux x64: the automated test suite passed 213 tests. The desktop and Daily renderer checks passed in Electron with a local stem song, including returning from Daily to Stems and Snippets and Karaoke playback.

## Updating

In the desktop app, choose **Help → Check for Updates**, or download the 1.13.9 installer for your computer from this release. Settings, songs and saved progress are preserved.

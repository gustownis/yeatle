# Yeatle 1.11.2

Fix the unwanted zoom/stretch of the tab labels and active underline when switching between Daily and Stems or Snippets on desktop.

## Fixes

- Daily now uses the same tab-strip layout as Stems and Snippets. The labels keep their size during the transition, and the full-width divider sits outside the animated strip.
- Keep the existing short desktop transition, reduced-motion support, and instant browser navigation.

## Verification

Windows checks cover the actual transition's start/end sizes, all six Daily routes, reduced motion, browser navigation, portrait layouts, Daily playback and copying, and Karaoke regression checks. See the [verification report](../testing-windows-1.11.2.md). Automated playback is muted. Physical microphone quality, Bluetooth, heat/memory and overnight tests remain pending; the packages remain unsigned.

## Updating

Choose **Help → Check for Updates**, or download the matching app below. Windows installer and Linux AppImage users can download and choose **Install and Restart**. Mac, Windows portable and Linux DEB users finish installation manually.

The `latest*.yml` files are updater metadata; `SHA256SUMS.txt` provides checksums. Settings and saved progress are preserved.

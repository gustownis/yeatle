# Yeatle 1.15

This release unifies account controls, Yeatle Wrapped, playback and display preferences, and desktop app tools into a single **Settings** window, simplifies Leaderboards, and cleans up the desktop app window on Windows and Linux.

## New

- **Unified Settings window and corner dock.** On desktop, the bottom-right corner shows **Wrapped** during Wrapped season until you hide it, then swaps to a **Settings** icon (and always shows **Settings** the rest of the year). On phones (`<= 560px`), the **Wrapped** / **Settings** button docks cleanly in the top header beside **Leaderboard** so it never overlaps the keyboard, song suggestions, or bottom buttons.
- **Account & Sync moved into Settings.** Sign in, account creation, manual sync, username changes, and log out now live under **Settings → Account & Sync**, keeping **Leaderboards** focused on rankings with a quick link to Settings at the bottom.
- **Gameplay, display, and storage controls.** Settings now includes **Master volume**, **Stems separation** (**Real (AI)** or **Light (Fast)**), **Snippets hints**, **Background photo** (**Full**, **Dim**, or **Off**), **Interface motion** (**Auto**, **Full**, or **Reduced**), a **Cached AI stems** size readout with **Clear cache**, and a collapsible **Keyboard shortcuts** reference.
- **Cleaner PC desktop app.** Windows and Linux desktop builds use a dark native window frame with the top menu bar removed, and desktop tools (**Check for Updates**, **Optional HQ Stems**, **Songs folder**, **Data & logs**, **Mic settings**, **Open in browser**, zoom, fullscreen, and reload) now live inside **Settings → Desktop App**. Standard shortcuts (`F11`, `F5`, `Ctrl+R`, `Ctrl+=`, `Ctrl+-`, `Ctrl+0`) continue to work, while the `/admin` panel remains available in browser/server mode.

## Verification

The automated test suite (`npm test`) ran locally on Windows x64 (`294` passed, `3` platform-specific skips) and runs across Windows, macOS, and Linux in the **Desktop builds** workflow before building each package. The packages are unsigned, and the installers were not tested on separate physical devices.

## Updating

On Yeatle 1.14.x desktop apps, choose **Help → Check for Updates** (starting in 1.15, choose **Settings → Desktop App → Check for Updates**), or download the 1.15 installer for your computer from this release. Settings, songs, and saved progress are preserved.

# Yeatle 1.13.2

This patch fixes the desktop app's packaged server files and restores tapping song suggestions in Daily on mobile browsers.

## Fixes

- **Desktop app startup after updating.** The desktop package now includes `client-signals.cjs`, fixing the `Cannot find module './client-signals.cjs'` startup error in 1.13 and 1.13.1.
- **Tapping Daily song suggestions on phones.** Tapping a suggestion in Daily now fills the guess box on iOS and other touch browsers when the input blurs before the tap completes, while scrolling through the suggestion list keeps it open without picking a song.
- **Linked open verses, features and duplicate entries from 1.13.1.** Open-verse demos and the features they became, songs listed under both Yeat and a collaborator, paired V1/V2 versions and merged duplicate tracker rows continue to answer for each other and share progress.

## Verification

Windows x64: the automated test suite passed 191 tests with one Windows symlink skip, including the packaged module check and Daily touch-suggestion check, and the packaged `app.asar` started the local server cleanly. The GitHub Actions workflow runs the test suite on Windows, macOS and Linux before building each package.

## Updating

If you installed 1.13 or 1.13.1 and cannot open the desktop app, download and run the 1.13.2 installer for your computer from this release. Earlier versions can also use **Help → Check for Updates**. Settings, songs and saved progress are preserved.

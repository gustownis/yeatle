# Yeatle 1.13.5

This patch fixes Daily scrolling on mobile phones, eliminates the black gutter gap on Karaoke, and recovers from overconstrained microphone errors on web.

## Fixes

- **Daily touch scrolling on phones.** Fixed an issue where Daily was unscrollable on mobile browsers by removing trapped overflow constraints on the page body and letting the document root scroll naturally with touch gestures.
- **Full-bleed Karaoke background.** Fixed an unwanted scrollbar gutter reservation on Karaoke that caused the background image to stop short of the right window edge with a black strip.
- **Resilient Karaoke microphone connection.** Fixed `OverconstrainedError` when opening a singer's microphone on the web by automatically falling back to available system audio settings and clearing disconnected device IDs.

## Verification

Windows x64: the automated test suite passed 193 tests with one Windows symlink skip, including a new test for overconstrained microphone fallback.

## Updating

In the desktop app, choose **Help → Check for Updates**, or download the 1.13.5 installer for your computer from this release. Settings, songs and saved progress are preserved.

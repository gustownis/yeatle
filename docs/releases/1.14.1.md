# Yeatle 1.14.1

This release opens Yeatle Wrapped in the desktop app now instead of on December 1, and fixes the server keeping files open after abandoned downloads and the Wrapped button opening two windows on a double tap.

## New

- **Yeatle Wrapped is open now.** Wrapped opens every year on November 16 instead of December 1 and stays viewable through January 7. Your 2026 Wrapped is ready as soon as you update: a one-time message announces it, and the button in the bottom-right corner reopens it. It keeps updating as you play until December 31, and play on January 1-7 counts towards 2027.

## Fixes

- **Tapping the Wrapped button twice opens one window.** On a slow connection, a second tap while Wrapped was loading opened a second window underneath the first.

## For server hosts

- **Abandoned downloads no longer leave files open.** When a player left partway through downloading a page file, a song splitter model or an HQ stem, the server kept that file open, and enough of them could stop it from opening any more files. Downloads now close their file with the connection. Responses, byte ranges and headers are unchanged.

## Verification

Linux x64: the automated test suite passed 261 tests (`npm test`), including new checks that abandoned downloads close their files and that a double tap opens one Wrapped window. Headless Chrome played Stems and Snippets rounds and checked Home, Daily and Karaoke against a local server with the full tracker, with no page errors and steady memory across rounds. The GitHub Actions workflow runs the test suite again on Windows, macOS and Linux before building each package. The packages are unsigned, and the installers were not tried on physical devices for this release.

## Updating

In the desktop app, choose **Help → Check for Updates**, or download the 1.14.1 installer for your computer from this release. Settings, songs and saved progress are preserved.

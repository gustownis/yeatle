# Yeatle 1.11.6

This patch makes admin visibility controls work consistently with catalog exclusions.

- Admin distinguishes **Hidden** songs from **Excluded** recordings, with accurate counts, an **Excluded only** filter and eligibility shown for each combined version.
- Hide and Show control eligible songs. **Clear manual hide** removes an older duplicate hide while keeping the recording excluded. Six redundant default hides have been removed without restoring their excluded recordings.
- Song test search and Play in game use the same eligibility rules as normal gameplay. Excluded recordings cannot be activated or added to the manual hide list again.
- Existing catalog exclusions, eligible Yeat versions, saved progress, downloaded files and pinned Daily challenges are preserved.

## Verification

The Windows automated suite passed 139 tests with one symlink-permission skip. Actual desktop and portrait Edge checks covered admin status, duplicate-hide cleanup, normal Hide/Show, combined versions and song test search. See the [admin verification](../testing-windows-admin-catalog.md) and [1.11.6 release verification](../testing-windows-1.11.6.md) for the checks actually performed.

The packages are unsigned. Physical microphones, singing accuracy and native macOS/Linux device behavior were not tested on this Windows PC.

## Updating

Choose **Help → Check for Updates**, or download the matching app from this release. Windows installer and Linux AppImage users can choose **Install and Restart**; other package types finish installation manually. Settings, songs and saved progress are preserved.

`SHA256SUMS.txt` provides download checksums. The three `latest*.yml` files are updater metadata.

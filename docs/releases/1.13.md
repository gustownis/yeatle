# Yeatle 1.13

This release moves Snippets rounds onto the server, starts the Daily from the Alivë era and gives players and admins more control over usernames.

## New

- **Snippets rounds run on the server.** The website picks each Snippets song and checks your guesses, and the song is revealed when you win or run out of tries. Wins from before this release keep counting on the leaderboard.
- **Change your username** from the 🏆 window. Your progress, rankings and other signed-in devices follow the new name.
- **Leaderboards update live** while the 🏆 window is open, including name changes.
- **The Daily now starts from the Alivë era.** Older songs are no longer picked.
- **Ready for the next Daily update.** This version can play the Daily the way the website will run it soon, with guesses checked by the website.
- **Faster loading.** The background, logo and tab icon are about 2.3 MB smaller.
- **Yeatle API.** Discord bots and other sites can read the leaderboards and the Daily's reset time and previous answer. See the [API guide](https://github.com/gustownis/yeatle/blob/main/docs/api.md).

## For admins

- **Players** lists every account with when it was created and last active.
- **Filtered usernames** blocks names on new and existing accounts ("This username was blocked because the song is dogshit"), and **Rename a player** gives any account a new name.
- **Replace today's Daily** picks a different song for the day when the chosen one shouldn't have been picked.

## Verification

Linux x64: the full automated test suite passed, and headless Chromium checked Snippets and Daily rounds and the admin panels against a local server. The GitHub Actions workflow ran the test suite again on Windows, macOS and Linux before building each package. The packages are unsigned, and the installers were not tried on physical devices for this release.

## Updating

Choose **Help → Check for Updates**, or download the matching app from this release. Settings, songs and saved progress are preserved.

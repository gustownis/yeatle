# Yeatle 1.13

This release keeps the answers on the server, adds automatic anti-cheat and gives players and admins more control over usernames.

## New

- **Snippets answers stay hidden.** The server picks each Snippets song and streams it under a random round id, checks every guess and only reveals the song when you win or run out of tries. Nothing in the browser can read the answer early, and only these server-checked wins count on the Snippets leaderboard. Wins from before this release keep counting.
- **Ranked karaoke is verified.** Ranked karaoke scores are checked against the song's length and the game's own scoring, and runs that match the song's original vocal are caught.
- **Anti-cheat.** Accounts are banned automatically for answers that arrive before or within moments of the audio, naming nearly every song from the first tiny clip, guessing faster than anyone can type, a known cheat panel on the page, or a karaoke run that is the song's own vocal. Banned players see a banned screen. Admins review every automatic ban and can undo it with the player's progress restored.
- **Change your username** from the 🏆 window. Your progress, rankings and other signed-in devices follow the new name.
- **Leaderboards update live** while the 🏆 window is open, including name changes.
- **The Daily now starts from the Alivë era.** Older songs are no longer picked.
- **The Daily can keep its answer on the server.** This version can play a Daily whose guesses are checked by the website; the website turns that on once enough players have updated.
- **Faster loading.** The background, logo and tab icon are about 2.3 MB smaller.
- **Yeatle API.** Discord bots and other sites can read the leaderboards and the Daily's reset time and previous answer. See the [API guide](https://github.com/gustownis/yeatle/blob/main/docs/api.md).

## For admins

- **Players** lists every account with when it was created and last active.
- **Filtered usernames** blocks names on new and existing accounts ("This username was blocked because the song is dogshit"), and **Rename a player** gives any account a new name.
- **Banned users** bans by username with an optional private reason, lists automatic bans for review, and keeps code captured from players' pages when something was injected into the game.
- **Replace today's Daily** picks a different song for the day when the chosen one shouldn't have been picked.

## Verification

Linux x64: the full automated test suite passed, and headless Chromium checked server-checked Snippets and Daily rounds, the banned screen, the admin panels and cheat capture against a local server. The GitHub Actions workflow ran the test suite again on Windows, macOS and Linux before building each package. The packages are unsigned, and the installers were not tried on physical devices for this release.

## Updating

Choose **Help → Check for Updates**, or download the matching app from this release. Settings, songs and saved progress are preserved.

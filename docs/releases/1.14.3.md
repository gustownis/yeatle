# Yeatle 1.14.3

This patch release brings the Leaderboard, Wrapped corner button, and cross-view controls in line with Yeatle's matte-black visual style, fixes accessibility and contrast across Karaoke and Stems/Snippets, and cleans up Wrapped navigation and sharing.

## UI and accessibility polish

- **Leaderboard.** The Leaderboard trigger button and modal now match Yeatle's matte-black surface, `6px`–`10px` corners, hairline borders, underline tabs, and hairline-divided rows instead of blurred purple cards and emojis. The player list scrolls independently while preserving scroll position and keyboard focus across live refreshes, and modal inputs and tabs support full keyboard navigation and focus trapping.
- **Wrapped.** The bottom-right Wrapped button now uses Yeatle's matte-black hairline style with a `–` minimize control and hides while the Wrapped window is open. Navigation and close buttons use centered vector icons with larger tap targets, tall slides scroll cleanly on small phones without top clipping, and the share preview omits the raw domain while **Copy text** includes the full `https://` link.
- **Karaoke and Stems/Snippets.** Karaoke primary buttons and active difficulty controls now use deep Yeatle purple (`#8901b9`) for WCAG AA contrast, the Karaoke header adds a dark backdrop bar so inactive mode tabs stay legible over the background photo, `index.html` adds `viewport-fit=cover` for notched phones, muted text contrast is raised on Stems/Snippets, and `prefers-reduced-motion` covers all UI transitions.

## Verification

Windows x64 (Node.js 24, Electron 44.7.0): the automated test suite passed (`npm test`, 278 passed, 3 skipped, 0 failed), and live browser verification checked the Leaderboard modal, Wrapped preview, and Karaoke header at desktop and mobile sizes with zero console errors. The GitHub Actions workflow runs the test suite across Windows, macOS and Linux before building each package.

## Updating

In the desktop app, choose **Help → Check for Updates**, or download the 1.14.3 installer for your computer from this release. Settings, songs and saved progress are preserved.

# Yeatle 1.9.5

This release restores conservative AI startup, makes failures visible, and reduces memory and repeated work. Real-song separation was checked on desktop and on a physical Android phone in Chrome Beta and Brave. The originally reported instant fallback did not reproduce in those hosted Android trials; this release provides an explicit reason and a correct Light selection whenever separation genuinely fails.

## What changed

- AI models prepare when Real stems is selected again. Brief listener detachment no longer cancels an unfinished round, and the worker no longer depends on the 1.9.4 model-download and lifecycle helpers.
- AI failures show their reason and switch the dropdown to Light. Selecting Real stems retries the current round, and a crashed worker is replaced.
- Idle AI sessions and their worker are released after one minute. Retired audio players now release their graphs and media listeners, reducing memory retained over long sessions.
- Reaching the final level stops unfinished separation while keeping the original full song, playback position, and seeking. The measured Android check used 5 model runs instead of 60.
- Rolling separation buffers reduced the measured worker accumulation and normalization storage from about 116 MiB to 8 MiB. Reused mask calculations preserve the original sample results, FFT windows, and snippet timing.
- Completed generated stems can survive reloads in a lossless browser cache, capped at 192 MiB total and 100 MiB per song. Audio and model content changes invalidate entries. A measured Chrome Beta reload took about 2.5 seconds with identical samples and zero new separation runs; model warmup can still occur.
- Persistent caching is skipped when browser privacy settings alter audio-buffer reads, as observed in Brave. AI separation remains available, and browser privacy settings are preserved.
- Admin song changes use an event stream, reconnect when the tab becomes visible, and handle server restarts. Installations without admin control skip these checks; polling remains available as a compatibility fallback.
- Song lists are compressed once per update, and compressed static downloads share a bounded cache. The measured song list transferred about 87.5% fewer bytes. Audio files and byte-range playback keep their existing behavior.
- The keyboard hint is hidden on phones and tablets. Narrow desktop windows and touch on a desktop keep the hint and shortcuts.

Hand-made stems, progress, settings, custom admin passwords, the smaller phone cache, and the 1.9.2 final-level playback fix are preserved. CPU/GPU selection and CPU thread defaults remain unchanged because the physical phone measurements varied with warming and run order.

## Updating

On desktop 1.9.1 or later, choose **Help - Check for Updates**. Windows installer and Linux AppImage users can download, then choose **Install and Restart**. Mac, portable Windows, and Linux DEB users download inside the app and finish installation manually. Desktop 1.9.0 users install manually.

- Windows: download `Yeatle-Setup-1.9.5-windows-x64.exe` for installation or `Yeatle-1.9.5-windows-x64-portable.exe` for a portable copy.
- Mac: choose `mac-arm64` for Apple Silicon or `mac-x64` for Intel, then download the DMG or ZIP.
- Linux: choose `linux-x64` for Intel/AMD or `linux-arm64` for ARM, then download the AppImage or DEB.
- Local browser version: [download the 1.9.5 ZIP](https://github.com/gustownis/yeatle/archive/refs/tags/v1.9.5.zip), keep your settings and song folders, and follow the [README](https://github.com/gustownis/yeatle#readme).

The `latest*.yml` files are updater metadata; `SHA256SUMS.txt` provides checksums. Players only need their app download.

For a hosted or local browser installation, update the full project and restart the server. Include `static-cache.cjs`, `live-control.cjs`, and every file in `build/assets/`, including `performance.mjs` and `stem-cache.mjs`. The AI worker is standalone. The [online version](https://playyeatle.duckdns.org/) receives these changes when its operator deploys the update; publishing this release does not deploy that website.

## Verification

All 43 automated tests pass. Desktop and physical Android checks covered real-song GPU/CPU separation, exact cached reloads, visible failure and retry, final-level cancellation, idle-worker release, snippet timing, and synchronized hand-made stems. The physical Android shortcut hint was hidden, while a narrow touch-enabled Windows desktop kept its hint and S shortcut. iOS Safari and lower-memory Android hardware remain untested.

These community desktop builds are unsigned, and Mac builds are not notarized. The original editable React source remains unavailable, so frontend changes use targeted patches to the supplied game bundle and readable helper modules.

The original game was vibecoded in its entirety and originated in the [Yeat Hub Discord community](https://discord.gg/twizz). Original project code uses the Unlicense; third-party libraries and media retain their own terms. The 1.9.2 playback fix was contributed by [fewmet](https://github.com/fewmet).

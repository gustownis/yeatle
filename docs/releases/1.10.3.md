# Yeatle 1.10.3

This maintenance update fixes browser mode switching and makes existing HQ stem packs work on Linux without renaming their audio files.

## Fixes

- Keep animated Stems/Snippets switches and navigation to/from Karaoke in the desktop app. Browsers switch modes immediately, including a browser opened from the desktop app's menu. Desktop transitions still respect reduced motion and device capability checks; the settings dropdown keeps its existing behavior on both platforms.
- Recognize capitalized stem filenames such as `Drums.mp3`, `Bass.mp3`, `Other.mp3`, and `Vocals.mp3` on Linux and other case-sensitive filesystems. Lowercase filenames and file symlinks continue to work. Incomplete packs, broken links, and folders named like audio files are left out of the HQ song list.
- Refresh the local-only song list when the tracker is unavailable, so completing or removing a stem pack takes effect without restarting the server. Saved tracker lists remain available when the tracker cannot be reached.

## Verification

- All 78 automated tests passed on Linux with Node.js 24 and 26. Additional checks cover interrupted transitions, count-in scheduling, pause and seek cleanup, mixed-case audio filenames, cache validation, byte ranges, and changes to local stem packs.
- Standalone Chrome and Brave passed rapid mode changes, karaoke loading with real HQ MP3 stems, the 3-2-1 count-in, saved volume after returning between modes, a narrow layout, and reduced motion, with no page errors.
- Native Electron checks covered desktop-only transitions, the black panel during switches, browser behavior without the desktop preload, and karaoke playback controls. Microphone permission used synthetic input; camera access was rejected.
- Human singing accuracy, audible output, physical microphone capture, Bluetooth latency, calibration, and long sessions still need hands-on checks. See the [Linux verification report](../testing-linux-1.10.3.md) for scope and reproducible checks.

## Updating

On desktop 1.9.1 or later, choose **Help → Check for Updates**. Windows installer and Linux AppImage users can download, then choose **Install and Restart**. Mac, portable Windows, and Linux DEB users download inside the app and finish installation manually.

- Windows: choose `Yeatle-Setup-1.10.3-windows-x64.exe` or `Yeatle-1.10.3-windows-x64-portable.exe`.
- Mac: choose the `mac-arm64` DMG/ZIP for Apple Silicon or `mac-x64` for Intel.
- Linux: choose the `linux-x64` or `linux-arm64` AppImage/DEB.
- Local browser version: [download the 1.10.3 ZIP](https://github.com/gustownis/yeatle/archive/refs/tags/v1.10.3.zip) and keep your settings and song folders when updating.

The `latest*.yml` files are updater metadata; `SHA256SUMS.txt` provides checksums. Players only need their app download. Desktop builds remain unsigned. Game progress, settings, song files, and admin passwords are preserved.

For a hosted update, deploy the full project and restart the server, including all files in `build/assets/`. The online version is expected to update automatically from this repository, according to its operator.

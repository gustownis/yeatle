# Yeatle 1.13.1

This patch links open-verse demos, features and duplicate tracker entries so any of their names is accepted as an answer.

## Fixes

- **Open verses and features answer for each other.** Open-verse demos and the features they became (such as `Yea!` and `Yung Bans - Yea Yea (feat. Yeat)`), songs listed under both Yeat and a collaborator, and paired V1/V2 versions now accept every member's dropdown name across 46 linked groups. Each song keeps its own recording, credits, release status and progress.
- **Duplicate recordings are merged.** Nine tracker pairs that share the same audio file, plus the released `Krank` and its `Lyfë` OG file row, now share one entry in song pools and suggestions and share progress.
- **Feature aliases and existing rounds.** Feature titles also accept their aliases with the lead artist in front, and linked answers work in today's Daily and Snippets rounds without changing saved challenges.
- **Default hidden songs.** The released `Krank` is no longer hidden by default; the hide moves to the 2 Alivë `Chains` demo, and the `vibewme` hide points to its current edit entry.

## Verification

Windows x64: the automated test suite passed 190 tests with one Windows symlink skip, including the linked-answer group checks. The GitHub Actions workflow runs the test suite on Windows, macOS and Linux before building each package. The packages are unsigned, and the installers were not tried on physical devices for this release.

## Updating

Choose **Help → Check for Updates**, or download the matching app from this release. Settings, songs and saved progress are preserved.

# Yeatle 1.13.11

This release moves the Daily reset to 12:00 AM EST/EDT (6:00 AM CET/CEST year-round), fixes the shared Daily date splitting between timezones, adds page- and mode-specific Discord embeds, and ships faster Home startup, smoother Karaoke loading, and lower audio and AI memory usage.

## What's new

- **Daily resets at 12:00 AM EST/EDT (6:00 AM CET/CEST).** The Daily challenge, leaderboard streaks, and public API now roll over at midnight US Eastern time (`05:00 UTC` in winter / `04:00 UTC` in summer), keeping the reset at 6:00 AM Central European time in both winter and summer time.
- **Same Daily date in every timezone.** The Daily page and copied share results now use the canonical challenge date rather than reformatting the timestamp in each player's local browser timezone, so players in Europe and the Americas always see and share the same date.
- **Page- and mode-specific Discord embeds.** Pasting links for Home, Stems (`/?mode=stems` or `/stems`), Snippets (`/?mode=snippet` or `/snippets`), Daily (`/daily`), Karaoke (`/karaoke`), or HQ Stems shows a purple (`#8901b9`) Discord embed matching that exact page or mode, and switching tabs on Home updates the `?mode=` URL automatically.
- **Faster Home startup and suggestion search.** Home no longer blocks first paint on `yeatle.js` or eager `AudioContext` startup, reuses a single `AudioContext` across rounds without copying stereo mixes unnecessarily, and speeds up song-suggestion indexing.
- **Smoother Karaoke loading and lower memory use.** Karaoke time-slices audio analysis so loading no longer freezes the main thread, batches persistent stem-cache reads in IndexedDB with cancellation checks, releases raw ONNX model buffers after loading, and reuses idle splitter workers while retaining less audio RAM.

## For server hosts

- **Request and download stream cleanup.** Hardens HTTP request parsing, rejects malformed URLs and invalid audio IDs with `400`, and cleans up stem download streams cleanly when declared lengths mismatch or downloads cancel.

## Verification

Windows x64: the automated test suite passed 245 tests with 2 POSIX-only tests skipped (`npm test`).

## Updating

In the desktop app, choose **Help → Check for Updates**, or download the 1.13.11 installer for your computer from this release. Settings, songs and saved progress are preserved.

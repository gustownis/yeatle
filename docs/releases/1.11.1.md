# Yeatle 1.11.1

Daily now looks and feels closer to Stems and Snippets, with matching song suggestions and a simpler way to copy your result.

## Improvements

- **Daily suggestions:** type a song name to see the same purple popup used by Stems and Snippets, including era/year labels. Pick with a mouse, touch, or the arrow keys and Enter. Choosing a suggestion fills the field without spending a try.
- Match Daily's panel width, spacing, clip bars, and purple controls to the other game pages.
- **Copy result** copies your date, score, six squares, and link directly. If clipboard access is blocked, the result stays selected for manual copying. The answer is never included.
- Smaller Yeatle logos on phones and portrait tablets leave more room for the game. Landscape desktop sizing is preserved; Karaoke's compact header also scales down in portrait.
- Give Windows the app's Yeatle taskbar identity. The isolated Daily test window now uses the Yeatle icon too.

## Updating

Choose **Help → Check for Updates** on desktop, or use the downloads below. Windows installer and Linux AppImage users can download and choose **Install and Restart**. Mac, portable Windows, and Linux DEB users finish installation manually.

- Windows: `Yeatle-Setup-1.11.1-windows-x64.exe` or `Yeatle-1.11.1-windows-x64-portable.exe`.
- Mac: `mac-arm64` DMG/ZIP for Apple Silicon, or `mac-x64` for Intel.
- Linux: `linux-x64` or `linux-arm64` AppImage/DEB.
- Local browser: [download the 1.11.1 source ZIP](https://github.com/gustownis/yeatle/archive/refs/tags/v1.11.1.zip), preserving your settings and song folders.

The `latest*.yml` files are updater metadata; `SHA256SUMS.txt` provides checksums. Normal clients continue to use the public shared Daily authority. Test profiles that explicitly use a local authority can have a different song.

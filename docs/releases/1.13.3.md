# Yeatle 1.13.3

This patch smooths the Leaderboard button transition across pages, adds a Microphone Settings shortcut in the desktop app and Karaoke, and cleans up page overflow on Daily and Karaoke.

## Fixes

- **Smooth Leaderboard button transitions.** The Leaderboard button now animates smoothly alongside the logo, mode tabs and page surface when switching between Stems, Snippets, Karaoke and Daily in the desktop app.
- **Karaoke microphone access in the desktop app.** Fixed a desktop permission check where Karaoke's audio frame was blocked with `Microphone access was blocked`, and added **Developer → Microphone Settings** (and a **Microphone settings** button in the desktop app when blocked) to open your computer's microphone privacy settings directly.
- **Cleaner Daily and Karaoke page overflow.** Fixed unwanted outer page scrolling on Karaoke's desktop setup screen and removed excess vertical overflow on Daily when the challenge fits in the window, while keeping Daily scrollable as guesses and results are added.

## Verification

Windows x64: the automated test suite passed 192 tests with one Windows symlink skip, and Electron desktop smoke checks verified the `yeatle-leaderboard` view-transition animation, Daily and Karaoke viewport fit (`scrollHeight === clientHeight` at 1280×860), and the `Developer → Microphone Settings` menu and Karaoke button.

## Updating

In the desktop app, choose **Help → Check for Updates**, or download the 1.13.3 installer for your computer from this release. Settings, songs and saved progress are preserved.
